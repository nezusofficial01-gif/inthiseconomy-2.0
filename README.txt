ENGINEERING ECONOMICS SOLVER - SINGLE FILE

Cukup upload index.html ke repository GitHub.
Tidak perlu Node.js, React, Vite, npm, package.json, atau folder src.

Untuk GitHub Pages:
1. Buat repository baru atau bersihkan repository lama.
2. Upload index.html ke root repository.
3. Buka Settings > Pages.
4. Pada Build and deployment pilih Deploy from a branch.
5. Branch: main, folder: /(root), lalu Save.
6. Tunggu beberapa menit dan buka URL Pages yang diberikan GitHub.

Jika tetap menggunakan Vercel:
- Hapus package.json, vite.config.js, dan file proyek React lama dari repository.
- Pastikan index.html ada di root.
- Build Command: kosongkan.
- Output Directory: .
- Install Command: kosongkan.

Aplikasi ini menghitung secara lokal di browser. Parser narasi hanya mengidentifikasi kandidat angka; bukan AI dan hasilnya wajib diperiksa.
